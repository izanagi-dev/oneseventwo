# OneSevenTwo

A 2D action game built in Godot 4.

## Current Features
* **Stance System**: Toggle between Melee (Wind), Missiles (Fire), and Magic (Rock) to parry incoming attacks.
* **Movement**: Responsive dashing and jumping mechanics.
* **Smart Enemies**: Enemy shooters that maintain distance from the player and telegraph their attacks.

## Controls
* **Move**: WASD / Arrow Keys
* **Jump**: Space
* **Dash**: Shift
* **Stances**: 1 (Wind), 2 (Fire), 3 (Rock)
